# Stock Market Simulator

A web application that simulates real stock market trading with real‑time data. Practice investing strategies without risking real money.

---

## 🚀 Features

### 🔹 Portfolio Management
- **Personal Portfolio Dashboard**  
  Track your investments, net worth, and daily performance.
- **Real‑Time Stock Updates**  
  See current stock prices updated during market hours.
- **Extended‑Hours Pricing**  
  View pre‑market and after‑hours stock prices.
- **Portfolio Performance Chart**  
  Visualize your portfolio value over time.
- **Daily Change Tracking**  
  See how your portfolio performs day‑to‑day.

### 🔹 Stock Trading
- **Buy & Sell Stocks**  
  Execute trades with real‑time pricing.
- **Market Search**  
  Find stocks by name or symbol.
- **Detailed Stock Information**  
  View key metrics and current price data.
- **Transaction History**  
  Track all your trades.

### 🔹 Watchlist
- **Customizable Watchlist**  
  Add stocks to monitor without purchasing.
- **Quick Access**  
  Easily view performance of stocks you’re interested in.
- **One‑Click Trading**  
  Trade directly from your watchlist.

### 🔹 Competition & Social
- **Leaderboard**  
  Compare your performance with other users.
- **View Other Portfolios**  
  See how top performers are investing.
- **Starting Balance**  
  Everyone begins with \$10,000 in virtual cash.

---

## 🎨 User Experience
- **Dark/Light Mode** — Choose your preferred theme.
- **Responsive Design** — Works on desktop and mobile.

---

## 🛠️ Technology Stack

### Frontend
- **React** — UI library for building the interface  
- **Vite** — Next‑generation tooling for faster development  
- **React Router** — Navigation and routing  
- **Material UI** — Component library for responsive design  
- **Context API & Custom Hooks** — State management and reusable logic  

### Backend & API
- **Firebase Authentication** — Secure user auth  
- **Cloud Firestore** — NoSQL database for user data & portfolios  
- **Cloud Functions** — Serverless functions for API calls & data processing  
- **Hybrid API Approach:**
  - **Yahoo Finance API** — Stock search and symbol lookup
  - **Finnhub API** — Real-time stock prices and market data
